# Case#2NeighborConsideredInHFunction-TriplePriorityQueue

## 项目简介

本项目是一个基于 Python 的栅格地图路径规划实验项目，核心目标是研究在 A* 算法中引入邻域信息和三优先级队列后的搜索效果。项目同时包含地图生成、边界与障碍物处理、场地检测以及结果可视化模块。

## 核心思路

传统 A* 算法通常根据下式评价候选节点：

```text
f(n) = g(n) + h(n)
```

其中 `g(n)` 是起点到当前节点的实际代价，`h(n)` 是当前节点到目标点的估计代价。项目在此基础上进一步考虑节点邻域信息，使启发函数能够感知局部环境，并通过三优先级队列组织待扩展节点，以平衡路径质量与搜索效率。

三优先级队列的具体排序规则以 `A_star.py` 中的实现为准。

## 算法流程

```text
读取或生成地图
    ↓
识别边界和障碍物
    ↓
设置起点和目标点
    ↓
初始化 A* 搜索结构
    ↓
计算节点代价和启发函数
    ↓
按优先级选择待扩展节点
    ↓
检查邻域并更新路径代价
    ├─ 找到目标点：回溯得到最终路径
    └─ 未找到目标点：继续搜索
    ↓
输出并绘制路径结果
```
